# Office Artifacts: The One-Line Placard Contest

A program that writes one museum placard line — an ordinary office object
(a binder clip) labelled as an ancient artifact, with catalogue date,
material and donor — to `/output/entry.txt`.

## The placard

> Binder clip, c. 2015. Spring steel, black enamel. A jaw trap for loose papers: once clamped, no document ever escaped. Donated by a survivor of the Great Audit.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic, no network. Writes a single line (1–180 characters) to `/output/entry.txt`.
